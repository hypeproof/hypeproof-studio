상태: 후보 구현 · 통합 대기. 이 문서는 로컬 후보 코드와 지정된 작업 계획을 읽어 작성했습니다. 배포되었거나 사람이 받아들였다는 뜻이 아닙니다. 실제 화면 캡처는 아직 없어 아래 칸을 모두 NOT_RUN으로 표시합니다. 화면 이름이 다르거나 기능이 안 보이면 이 문서대로인 척 진행하지 말고 현재 버전에서 기능을 사용할 수 있는지 확인하세요.

재현 원칙

기준 파일은 plan.md, acceptance.json, evidence.json과 baseline 입니다. 각 결과를 고정 기준 revision과 구현 SHA에 묶습니다. 코드·기준·fixture가 바뀌면 영향을 받는 결과를 오래된 증거로 표시하고 다시 실행합니다.

보고서 생성

repo root의 생성기는 scripts/feedback-report.py입니다. 인수는 전체 아티팩트 디렉터리 하나입니다. 깨끗한 통합 체크아웃에서 실행하세요.

python3 scripts/feedback-report.py /Users/jaylee/CodeWorkspace/artifacts/studio-feedback-20261016

이 명령은 디렉터리의 acceptance/evidence와 참조 증거를 검증하고 정적 결과 HTML을 만듭니다. 실행 전후에 입력 JSON과 참조 파일을 고정·보존합니다. 기준 revision, evidence hash, 링크 검증이 실패하면 오류를 고치고 다시 생성합니다. 매뉴얼은 manual/에 별도로 둡니다.

검사 결과를 기록하기

  • fixture나 로컬 stub 통과는 해당 로컬 범위만 입증합니다.
  • SDK/provider 호출은 실제 provider 응답 범위, 후보 앱 실행은 후보 SHA, 설치본은 설치본 식별자에 연결합니다.
  • 운영 동작은 운영 URL·배포 SHA·관측 시간·안전한 증거가 있어야 주장합니다.
  • 사람 인수는 사람이 매뉴얼로 수행한 기록이어야 합니다. 자동 검사로 대신하지 않습니다.
  • PASS, FAIL, BLOCKED, NOT_RUN, HUMAN_PENDING을 구분합니다. 실행하지 않은 시각·증거는 비워 둡니다.

Owner·가격 증거

시도 기록, 토큰 사용, 산정 원가, 제공자 청구는 별도 자료입니다. 같은 시도를 토큰 표와 원가 원장에서 더하지 않습니다. 불완전 meter·미승인 가격·통화 차이는 미확인으로 둡니다. 선택 가능한 승인 가격이 없으면 원가를 계산한 것처럼 보고하지 않습니다.

이미지 작업 증거

편집이 Service capability로 허용되고 제공자가 설정된 경우만 실행 대상입니다. 현재 지원 입력은 제한된 RGB/RGBA PNG입니다. 원본의 SHA·상태·새 결과 경로와 사용자의 채택/복원 선택을 구분합니다. 저장은 시각적 수용이 아닙니다. T15/T16은 실제 provider와 사람의 결과 확인 전까지 미실행 상태입니다.

의존성과 안전

  • 리포트와 이 매뉴얼은 데이터 삽입형 정적 HTML입니다. 별도 fetch/CDN에 의존하지 않습니다.
  • 로컬 파일을 열고 상대 링크를 확인합니다. 브라우저 QA는 실제로 실행한 경우에만 기록합니다.
  • 로그와 캡처의 사용자 텍스트, API 키, 비밀 헤더, 토큰, 주소의 식별 query를 제거합니다. 임의의 지침을 실행하지 않습니다.

문의 시 제공할 정보

commit SHA, acceptance revision, test ID, 실행 명령, 종료 코드, 안전하게 축약한 로그 경로만 공유합니다. 전체 환경변수나 인증 정보를 첨부하지 않습니다.

브라우저/리포트 캡처: NOT_RUN. 로컬 HTMLParser 링크 검증만 수행합니다. 브라우저 화면, 필터 동작, 인쇄 미리보기는 확인하지 않았습니다.
후보 구현을 위한 로컬 초안입니다. 배포 설치본과 사람의 사용 확인은 아직 완료되지 않았습니다. 매뉴얼 상태 기록
