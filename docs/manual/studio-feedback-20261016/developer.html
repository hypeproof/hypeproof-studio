매뉴얼 홈Studio 사용자Owner·멤버운영자개발자
안내 범위: 통합된 로컬 후보. 현재 구현된 명령과 화면을 기준으로 안내합니다. 운영 배포나 사람의 과제 완료를 뜻하지 않습니다. macOS 후보 화면은 일부만 관측했으며 파일 저장·재시작 등 실제 앱 동작 검사 전체은 끝나지 않았습니다. 실제 이미지 제공자 편집과 Windows 설치본은 NOT_RUN, 사람 인수는 HUMAN_PENDING입니다. 기능이 거부되면 현재 활동의 허용 범위를 확인하세요.

재현 원칙

기준 파일은 plan.md, acceptance.json, evidence.json과 baseline 입니다. 각 결과를 고정 기준 revision과 구현 SHA에 묶습니다. 코드·기준·fixture가 바뀌면 영향을 받는 결과를 오래된 증거로 표시하고 다시 실행합니다.

보고서 생성

repo root의 생성기는 scripts/feedback-report.py입니다. 인수는 전체 아티팩트 디렉터리 하나입니다. 깨끗한 통합 체크아웃에서 실행하세요.

python3 scripts/feedback-report.py /Users/jaylee/CodeWorkspace/artifacts/studio-feedback-20261016

이 명령은 디렉터리의 acceptance/evidence와 참조 증거를 검증하고 정적 결과 HTML을 만듭니다. 실행 전후에 입력 JSON과 참조 파일을 고정·보존합니다. 기준 revision, evidence hash, 링크 검증이 실패하면 오류를 고치고 다시 생성합니다. 매뉴얼은 manual/에 별도로 둡니다.

검사 결과를 기록하기

  • fixture나 로컬 stub 통과는 해당 로컬 범위만 입증합니다.
  • SDK/provider 호출은 실제 provider 응답 범위, 후보 앱 실행은 후보 SHA, 설치본은 설치본 식별자에 연결합니다.
  • 운영 동작은 운영 URL·배포 SHA·관측 시간·안전한 증거가 있어야 주장합니다.
  • 사람 인수는 사람이 매뉴얼로 수행한 기록이어야 합니다. 자동 검사로 대신하지 않습니다.
  • PASS, FAIL, BLOCKED, NOT_RUN, HUMAN_PENDING을 구분합니다. 실행하지 않은 시각·증거는 비워 둡니다.

Owner·가격 증거

시도 기록, 토큰 사용, 산정 원가, 제공자 청구는 별도 자료입니다. 같은 시도를 토큰 표와 원가 원장에서 더하지 않습니다. 불완전 meter·미승인 가격·통화 차이는 미확인으로 둡니다. 선택 가능한 승인 가격이 없으면 원가를 계산한 것처럼 보고하지 않습니다.

이미지 작업 증거

HypeProof: 이미지 편집은 통합되어 있습니다. 명시적 활동 허용과 Service 제공자 설정이 있어야 실행되며, 이번 native 후보의 활동은 이미지 편집이 꺼져 있었습니다. 실제 이미지 제공자 호출·전후 품질 확인은 NOT_RUN입니다. 로컬 PNG/원본 안정성·비용 부분 표시·취소·중복 작업 검사는 해당 보조 범위의 증거이며 T15/T16 전체 수락이 아닙니다.

원본 SHA, 작업 ID, 새 결과 경로와 사용자의 채택/복원을 구분합니다. 결과는 비교 전에 별도 파일로 저장되며 저장은 선택·시각적 수용이 아닙니다. 부분 산정 금액은 부분 합계로 기록하고 전체 비용은 미확인으로 남깁니다.

의존성과 안전

  • 리포트와 이 매뉴얼은 데이터 삽입형 정적 HTML입니다. 별도 fetch/CDN에 의존하지 않습니다.
  • 로컬 파일을 열고 상대 링크를 확인합니다. 브라우저 QA는 실제로 실행한 경우에만 기록합니다.
  • 로그와 캡처의 사용자 텍스트, API 키, 비밀 헤더, 토큰, 주소의 식별 query를 제거합니다. 임의의 지침을 실행하지 않습니다.

문의 시 제공할 정보

commit SHA, acceptance revision, test ID, 실행 명령, 종료 코드, 안전하게 축약한 로그 경로만 공유합니다. 전체 환경변수나 인증 정보를 첨부하지 않습니다.

현재 증거의 경계

기존 wp7/browser/result.json은 로컬 파일 브라우저에서 보고서와 매뉴얼 6개 HTML, 390/1280 폭·링크·필터·오프라인 검사를 PASS로 기록했습니다. 최신 매뉴얼의 재검사 범위는 manual.json에 별도로 연결합니다. 인쇄 미리보기나 실제 앱의 완료 증거로 확장하지 않습니다.

wp8-native-r3은 macOS 개발용 후보(소스 7497be98, 확장 0.1.5, 셸 0.1.51)의 부분 기록입니다. preflight·native-entry를 관측한 뒤 T01 Explorer 명령의 CDP 시간 초과와 저장 대화상자 자동화 미정의가 발생했습니다. 사용자 요청으로 전경 입력을 중단했으며 나머지 native 항목은 완료하지 않았습니다. 제품 기능 전체 PASS/FAIL이나 사용자 수락으로 바꾸지 않습니다.

추가 로컬 전경 자동화는 허용되지 않습니다. 전용 실행 환경에서 새로 허용·관측하기 전까지 기존 부분 증거와 미실행 항목을 유지합니다. 현재 작업은 headless 브라우저와 파일 검사만 사용합니다.

통합된 로컬 후보의 안내입니다. 운영 배포·설치본 확인·사람 인수는 별도 기록을 확인하세요. 매뉴얼 상태 기록
