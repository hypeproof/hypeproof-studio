운영자

매뉴얼 홈Studio 사용자Owner·멤버운영자개발자
상태: 후보 구현 · 통합 대기. 이 문서는 로컬 후보 코드와 지정된 작업 계획을 읽어 작성했습니다. 배포되었거나 사람이 받아들였다는 뜻이 아닙니다. 실제 화면 캡처는 아직 없어 아래 칸을 모두 NOT_RUN으로 표시합니다. 화면 이름이 다르거나 기능이 안 보이면 이 문서대로인 척 진행하지 말고 현재 버전에서 기능을 사용할 수 있는지 확인하세요.

운영 범위

Owner 페이지는 활성 멤버의 읽기 전용 조회 흐름입니다. 권한 변경, 가격 승인, 배포와 결제 처리는 이 화면의 사용량 조회와 별도 결정입니다. 운영 작업은 본인이 가진 역할과 정식 배포 절차 안에서만 수행합니다.

접근 확인

  1. 멤버 원장과 현재 활성 여부를 승인된 관리 경로에서 확인합니다. Owner 화면의 403은 권한을 직접 바꾸라는 뜻이 아닙니다.
  2. 사용자 비활성화나 권한 취소는 권한 있는 담당자에게 정식 절차로 요청하고 요청 번호·효력 시각을 기록합니다.
  3. SSO가 필요하거나 DB 장애(503)가 난 경우 공개 로그나 리포트에 비밀을 남기지 말고 안전한 운영 경로로 담당자에게 전달합니다.

수집·가격·대조 상태

  • 수집은 서버 경로를 통과해 기록된 시도 범위를 설명합니다. 개인 키로 직접 요청했거나 서버로 전송되지 않은 호출은 여기서 보이지 않을 수 있습니다.
  • 실패, 중단, 부분 응답, 보강 대기 기록은 성공·무료·완료로 바꾸지 않습니다. 누락된 원인과 범위를 확인하고 미확인을 남깁니다.
  • 가격 revision은 근거가 필요합니다. 선택 가능한 정확한 가격이 없으면 원가가 미확인으로 남습니다.
  • 새 가격 후보를 준비할 수는 있지만, 계정 조건과 가격 출처를 사람이 확인하고 승인하기 전에는 운영 값으로 적용하지 않습니다.
  • 제공자 사용량·인보이스가 있으면 같은 기간·계정·모델·통화·범위를 맞춰 대조합니다. 제공 자료가 없으면 T30은 완료가 아닙니다.

장애 진단과 복구

표시조치
401 로그인 필요사용자에게 기존 SSO로 다시 인증하도록 안내합니다. 비밀 값을 수집하지 않습니다.
403 활성 멤버 권한 없음멤버 상태와 권한 담당자 확인 후 승인된 절차로 처리합니다. 인증을 우회하지 않습니다.
400 잘못된 기간날짜 형식과 종료일을 확인하고 366일 이하 범위로 재조회합니다.
422 항목이 많음날짜 범위를 줄여 조회합니다. 일부 결과만 전체 결과로 보고하지 않습니다.
503 조회 불가최근 배포·DB 상태를 살피고 재시도는 장애가 해소된 뒤 합니다. 화면에서 숫자를 추정해 채우지 않습니다.
가격/사용량 미확인원본 attempt·meter·승인 가격 revision·제공자 대조 자료를 확인합니다. 원기록을 덮어쓰지 말고 새 근거와 revision으로 정정합니다.

배포와 롤백

배포 후보의 정확한 SHA, 호환성 검사, 승인된 릴리스 경로, 실제 관측을 먼저 연결합니다. CI 성공만으로 운영 반영이라고 쓰지 않습니다. 회귀가 있으면 영향 계층의 마지막 검증 버전으로 정식 롤백하고 실제 상태를 다시 확인합니다. 원가 원장이나 기록을 지워 롤백하지 않습니다.

안전한 지원 정보

보낼 수 있는 정보: UTC/KST 시각, 안전한 request/job ID, status/error code, 서비스·앱 SHA, 범위가 축소된 로그 위치와 재현 단계. 보내지 말아야 할 정보: Service secret, 토큰, 인증 코드, 쿠키, 제공자 API 키, 사용자 대화·이미지 원문, 불필요한 개인정보. 스크린샷은 공유 전에 화면과 URL의 민감 부분을 가립니다.

운영 화면/장애 캡처: NOT_RUN. 운영 상태를 실제 관측하지 않았습니다. 샘플 화면을 운영 증거로 사용하지 마세요.
