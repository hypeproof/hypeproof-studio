## CGP-KNOW-R-025: memory overview by task (2026-10-29, agent-selected conservative implementation)

Applies DEC-01 (local files only) and the owner note to be conservative with minors' data. Built as REQ-STUDIO-MEMORY-OVERVIEW.

- "Generated" means built by Studio from the memory files, not written by a model. A model summary would send memory in a request before the REQ-KNOW-49 first-use notice and the REQ-KNOW-44 count exist, and could itself produce the evaluative sentences this row forbids. Each overview item is one file's own text.
- Grouping needs a task per item, and R-030 files had none. An item kept from a task now records it on the file's first line as a Markdown comment with a plain id; files without it group under "작업 정보가 없는 기억". The writer for turn-made memories (REQ-KNOW-45) passes the task id to `append()`.
- The check is a word and shape list, not language understanding. Capability keys are matched as written (upper case) so English words such as "context" in a fact pass; of the Korean labels only the ones that do not read as everyday words are listed, and two-syllable labels (검증, 판단, 의도, 맥락…) are refused only next to an ability noun. Refused items are left out of the overview and counted, never deleted, so a too-strict match costs one line of overview and no data.
- "Unavailable for minor cohorts" uses `isMinorProfile`, which fails closed: an unknown or missing tier counts as a minor, so only known adult tiers (`website`, `search-webapp`) see the overview. DEC-02 keeps memory itself (files, list, delete) on for every cohort.
- A correction is the learner's words for one item, typed in place (one field per item rather than a single free-text box at the bottom; DES-KNOW-43 may restyle it). It is saved as a new file in the same task and the old file is removed, so the store keeps its append-plus-learner-delete contract. No native confirm: the learner typed the words and pressed save, and the old text is visible in the field until then. A correction that fails the check is refused with a reason rather than stored.
- Fix round 1 (2026-10-29, after the privacy verify): the check now compares a lower-cased, look-alike-folded, invisible-free copy and a space-free copy; capability keys are refused in any case (lead ruling: so "context" and "intent" in an English fact are refused too); a short capability label followed by an evaluative word is refused; deficit, habit and person-type words without a pronoun, health, diagnosis and emotional-state words, and spelled-out jamo were added. Everyday words that hold a stem (요약해, 예약해, 아이디어, 라이센스, 장애물, 불안정, 타입스크립트) are exempted so ordinary task memories stay. Overview stays unavailable for minor cohorts (acceptance text); a follow-up may offer 고치기 on the file list for every seat.
