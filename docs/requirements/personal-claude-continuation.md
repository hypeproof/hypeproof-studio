Status: implementation candidate for Studio [#2485](https://github.com/hypeproof/hypeproof-studio/issues/2485), under ongoing Epic [#1782](https://github.com/hypeproof/hypeproof-studio/issues/1782). This contract does not establish release, deployment, general availability, or customer acceptance.

## Intent and parent requirements

[Product Intent](../PRODUCT-INTENT.md) (`ST-INT-NATIVE`) requires Useful work first, Human judgment stays visible, Minimum necessary intervention, and Evidence over claims. When free AI stops, the learner retains the work and chooses the next action. Context selection, payment responsibility, and result verification stay visible decisions. Context, Verify, Delegate, and Ownership are possible observations, never ability scores inferred merely from sending a request.

This is a bounded continuation of [native trial requirements](studio-native-trial.md) (`ST-REQ-NATIVE`, especially NAT-02/07/11/12), with the [outbound consent contract](../research/chatgpt-desktop-2026-10/domains/projects-library-memory.md#req-know-09-implementation-contract-cgp-know-r-006) (`ST-REQ-OUTBOUND-CONSENT`, REQ-KNOW-09). Existing class access, expiry, budget, and purchase rules remain authoritative. This personal transport is not a general replacement of the Service coach runtime.

## Public handoff and experimental adapter

The customer path is a manual official-client handoff: Studio prepares reviewed text for the local clipboard. It does not inspect a Claude account, invoke the CLI, or send an AI request. Preparing and copying the payload does not require an installed CLI. The learner separately opens the official Claude Code client (`claude`), checks its actual account and funding, and chooses whether to paste and send there. The learner may then paste an answer back and explicitly save it to the original task as `직접 가져온 답변`; Studio does not attest that an imported answer came from the provider.

Automated CLI inference is an experimental development adapter enabled only when **both** `vscode.env.appName === 'HypeProof Studio Dev'` and `HPS_PERSONAL_CLAUDE_EXPERIMENT=1`. Neither condition alone enables it. General availability of subscription-backed automatic inference is **BLOCKED pending distribution/authentication confirmation**; an installed official CLI and successful technical checks do not establish that confirmation.

Official sources checked on 2026-10-23 have different scopes. [Log in to your Claude account](https://support.claude.com/en/articles/13189465-log-in-to-your-claude-account) describes native-app subscription use, directs products for others toward API authentication, and allows discretionary third-party access with possible usage-credit charges. [Use the Claude Agent SDK with your Claude plan](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan) says the paused changes still permit SDK, `claude -p`, and third-party usage against subscription limits and describes newer API credits. These statements do not resolve Studio's distribution/authentication boundary. This is a documented uncertainty, not a claim that subscription use is categorically prohibited or approved for this product.

## Behavioral contract

| ID | Required behavior |
|---|---|
| PCC-01 | Offer `개인 Claude Code로 이어하기` only in a personal, non-instructor, nonminor free workspace after the end card is advertised. Require exactly `profile_id: studio-open-trial`, `activity_kind: trial`, and no `pass` block. A code-issued `studio-native-trial`, class/minor seat, paid pass, unknown/mismatched profile, or stale/forged offer cannot open it. |
| PCC-02 | Keep current task, files, original conversation, and composer draft. Cancellation, copy/save failure, disconnect, or failed official-client use do not remove or replace that work. Offer `AI 없이 작업으로 돌아가기`. Optional answer import requires an explicit save and appends a `직접 가져온 답변` exchange to that same task only, without claiming provider verification. |
| PCC-03 | Prepare only project label, editable request, explicitly pasted/selected text, and optional current-task user/assistant text history; history defaults off. Never automatically include files, hidden memory, other tasks, credentials, or attachments. Show the complete system prompt and serialized payload, the clipboard destination, and the need to check actual account/funding in the official client. No CLI installation or account inspection is needed to review/copy. |
| PCC-04 | Clipboard approval is unchecked by default, bound to the complete reviewed payload and current generation/scope, valid for at most five minutes, and consumed by one copy. Editing request/material/history, cancellation, expiry, disconnect, or task/activity change invalidates it. Copy consent authorizes local clipboard placement only; the user separately decides the official-client send. A stale callback/import cannot append to a different task. |
| PCC-05 | Public mode never invokes the CLI inspector or inference transport. Studio does not read credentials, keychains, token files, or passwords and does not implement OAuth. The learner installs/logs in to/opens the official client independently and checks its recipient, account, model, policy, and funding before sending. No automatic launch, login, purchase, retry, account switch, or Studio-pass fallback occurs. |
| PCC-06 | Experimental inference requires both exact Dev identity and explicit environment opt-in. Its early scope is a verifiable first-party `claude.ai` personal Pro/Max account and supported CLI/policy. API-key, cloud, Team/Enterprise, managed/unknown policy, helper-based or unverifiable configuration blocks automated dispatch and directs the learner to the official client. Preserve official auth/provider configuration; never strip it to select cached subscription auth. |
| PCC-07 | The personal account's subscription, credits and configured extra usage apply in the official client; the learner checks possible charges there. A subscription does not promise zero incremental cost. Studio does not enable extra usage, purchase, silently retry, change model/provider/account, or fall back to its own pass. Experimental sends additionally show the verified recipient/account/funding, model, full payload and explicit one-use consent, with predispatch reinspection and invalidation on change. |
| PCC-08 | Studio's public handoff is text only and does not automatically edit project files. The experimental adapter returns text coaching, runs in an empty temporary cwd, disables tools/MCP/hooks/connectors/workspace instruction discovery/session persistence/retries/fallback through supported CLI controls, bounds request/reply size and lifetime, aborts on cancellation and ignores late responses. It cannot claim file edits, commands, or external actions. The learner controls any actions independently performed in the official client. |
